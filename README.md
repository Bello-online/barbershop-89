# Barbershop 89

Landing page for Barbershop 89, 205 Quigley Road, Unit 3, Hamilton, Ontario.

A static site: `index.html`, `styles.css`, `main.js` and the `media` folder. No build step. Open `index.html` in a browser, or serve the folder with any static server.

- Bookings go to the shop's Fresha page.
- The hero film and the chair reel are the shop's own Instagram videos.
- The open-now line is computed in the browser from the shop's hours in Toronto time.
